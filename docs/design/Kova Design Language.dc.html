Kova Design Language · v1

Calm by default. Colour only when something is on.

The foundations every Kova screen is built from. Tokens live in styles.css, with one file per concern under tokens/.

Principles

Colour means stateSurfaces are neutral. Amber appears only where a light is on or an action is primary, so you can read a screen at a glance.
Depth dialEvery object has Simple, Details and Code tabs. Power sits one layer down and is never in the way.
Flat, stepped depthHierarchy comes from lightness steps, not borders or shadows. Shadows are only for things that float: toasts and drawers.
Plain words, real numbers“8 lights on”, not “Lighting status: Active”. Names come before ids. Times use the 24-hour clock.
